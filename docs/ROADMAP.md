# Roadmap — Mezquita Arrahma v2

## ✅ Completado
- Estructura HTML de la web (SPA de una sola página).
- Integración con Supabase (horarios, contacto, email, teléfono).
- Sistema de internacionalización (i18n) con `assets/i18n.js`.
- Configuración SEO: meta tags, Open Graph, Twitter Cards.
- Despliegue en Cloudflare Pages.
- Tipografías personalizadas (Outfit, Playfair Display, Amiri, Cairo).
- Rediseño premium de la sección Hero y Horarios (layout grid).
- Botones de acceso directo al Corán y PDF, menú móvil interactivo.
- Botones de cabecera en escritorio alineados al menú móvil (remplazo de Donar por "Leer y Escuchar el Corán").
- Estilización premium con gradiente dorado para enlaces del Corán en móviles y escritorio.
- Animación de carga (Preloader) con branding de la mezquita (2s de duración).
- Creación de documentación de sesiones (`docs/`).

## 📋 Próximas mejoras prioritarias
1. **Optimizar código base** — separar CSS y JS en archivos independientes para mejorar la estructura y rendimiento.
2. **Accesibilidad (a11y)** — añadir atributos `aria-*` de manera exhaustiva y textos `alt` descriptivos para navegación accesible.
3. **PWA (Progressive Web App)** — permitir a los usuarios instalar la app web y ver horarios offline.
4. **Galería de imágenes** — añadir una sección con fotos de la mezquita, clases o eventos, si se dispone de suficiente contenido.
5. **Formulario de contacto** — explorar la posibilidad de conectarlo con la API de Supabase o servicios de correo.
